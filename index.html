Вопросы и ответы

Часто задаваемые вопросы

Банят ли за использование ShinyVisuals на серверах?
Нет. ShinyVisuals — это исключительно клиентский косметический мод и оптимизатор рендера. Он не вмешивается в сетевые пакеты передвижения или ванильную физику сервера, поэтому безопасен для игры на FunTime, ReallyWorld, HolyWorld и серверах анархии.
Совместим ли мод с шейдерами Iris и модом Sodium?
Да, клиент полностью построен вокруг современного графического стека Fabric и бесконфликтно работает параллельно с Sodium, Iris Shaders, Lithium, FerriteCore и другими оптимизаторами.
Какая версия Java требуется для работы?
Для Minecraft 1.21.4 требуется Java 21 (или новее). Практически все современные лаунчеры (TLauncher, Prism, Modrinth) загружают нужную версию Java автоматически при выборе версии игры.
